Stay backend help

How to run your guesthouse on amaldives STAY — reservations, website, OTAs, payments, and day-to-day operations.

Introduction

amaldives STAY is your property management system: admin dashboard, guest website, direct bookings, OTA calendar sync, housekeeping, finance, and guest services.

Your property can be reached on:

  • Custom domain (e.g. rivethibeach.com) — guest marketing site + sign-in
  • STAY subdomain — https://your-slug.stay.amaldives.com
This page personalizes URLs when opened from Admin → Help. You can also pass ?subdomain=your-slug in the address bar.

Dashboard

The dashboard shows occupancy, today’s check-ins/out, open tasks, revenue snapshot, and recent bookings.

  • Use the property switcher in the sidebar if you manage multiple properties.
  • Use the tenant switcher if your account belongs to more than one guesthouse.

Reservations

Create a booking

  1. Reservations → New or walk-in from the availability calendar.
  2. Pick room, dates, guest details, and source (Direct, OTA, Agent).
  3. Confirm — status becomes CONFIRMED (or PENDING for unpaid online bookings).

Booking statuses

StatusMeaning
PENDINGAwaiting payment (e.g. Stripe checkout not completed)
CONFIRMEDActive reservation; blocks availability
CHECKED_INGuest in house
CHECKED_OUTStay completed
CANCELLEDCancelled; dates released

Sources

Bookings may come from direct (website), admin, OTA iCal sync, or B2B agents. Filter by source in the reservations list.

Availability calendar

Admin → Availability shows per-room occupancy plus external blocks from Booking.com / Airbnb iCal feeds.

  • Green = available · Red = booked · External blocks show the OTA source.
  • Click a cell to start a new reservation for that room and date.

Rooms & pricing

Rooms

Each physical room has a number, display name (room type), base price, amenities, photos, and capacity. The public booking widget groups rooms into offers by type and price.

Pricing & promotions

  • Promotions — discount codes and seasonal offers.
  • Rack rate — optional strikethrough “was” price on the website.

Travel agents

Guest website

Admin → amaldives Page edits your public site: photos, highlights, amenities, room descriptions, and the homepage booking widget.

  • Profile tab — property story, stats, gallery.
  • Branding — logo, colors, hero image.
  • Domain — point your custom domain (e.g. rivethibeach.com) to STAY.

Direct booking

Guests book from the homepage hero or /book. Flow:

  1. Choose check-in, check-out, guests → Search.
  2. Select a room type (not individual room numbers).
  3. Optional airport transfer and add-ons.
  4. Guest details → Card (Stripe) or Pay at property.
Stripe bookings stay PENDING until payment completes. They do not block OTA calendars until confirmed.

Stay — open Channel Manager (screenshots)

  1. Sign in → left sidebar Web & Distribution (click to expand).
  2. Click Channel Manager (not “amaldives Page”).
  3. Or open /admin/web?tab=channels directly.

A) Copy Stay URL → paste into OTAs

Top green box: Your iCal Availability Feed. Click the copy icon next to the URL (or use Test Feed).

https://stay.amaldives.com/api/public/your-slug/calendar.ics

Custom domain (same file):

https://your-domain.com/api/public/your-slug/calendar.ics

B) Copy OTA URL → paste into Stay

Scroll to Block dates from Booking.com / Airbnb:

  1. Source dropdown (Booking.com / Airbnb / Vrbo / Other).
  2. Room dropdown — pick the matching Stay room (not “All rooms” unless whole property closed).
  3. Paste OTA export URL in the long URL field (placeholder shows ical.booking.com).
  4. Optional Label (e.g. “Booking.com — Deluxe Sea View”).
  5. Click teal Add feed.

After adding: use Sync now on each row; check Last sync and block count.

Multi-room: Stay’s export URL is property-wide (all confirmed bookings). Each OTA import feed should map to one Stay room. Re-importing the same Stay URL on every Booking.com room type can over-block.

Booking.com — exact clicks

Login: admin.booking.com

Find export link (Booking.com → Stay)

  1. Rates & availability (left menu).
  2. Calendar → select the room/rate plan you sell on Booking.com.
  3. Sync calendars (or calendar sync icon).
  4. Under Export calendar → Copy link (URL like https://ical.booking.com/v1/export?…).
  5. Paste into Stay → Add an iCal feed (see screenshot above).

Paste Stay link (Stay → Booking.com)

  1. Same Sync calendars screen.
  2. Import calendar → paste Stay export URL → confirm.
  3. Booking.com refreshes imports about every 6–12 hours (their schedule).

Airbnb — exact clicks

Login: airbnb.com/hosting → select listing

Find export link (Airbnb → Stay)

  1. Open the listing → tab Calendar.
  2. Availability settings (gear / settings on calendar).
  3. Connect calendars or Connect to another website.
  4. Export calendar → copy the link (often https://www.airbnb.com/calendar/ical/…).
  5. Paste into Stay Add feed · source Airbnb · matching room.

Paste Stay link (Stay → Airbnb)

  1. Same Availability settings panel.
  2. Import calendar → paste Stay URL → name the calendar (e.g. “Stay PMS”) → Import.
  3. Airbnb typically refreshes every ~2 hours.

Expedia / Hotels.com — exact clicks

Login: expediapartnercentral.com

Find export link (Expedia → Stay)

  1. Select property → Rooms and rates (or Inventory).
  2. Open the room type → Calendar sync / iCal.
  3. Export calendar → copy URL.
  4. Stay: source Other, label “Expedia — …”, paste URL, Add feed.

Paste Stay link (Stay → Expedia)

  1. Same calendar sync area → Import calendar / Add external calendar.
  2. Paste Stay export URL → save.

Vrbo / HomeAway — exact clicks

Login: vrbo.com → host dashboard → listing

Find export link (Vrbo → Stay)

  1. Listing Calendar.
  2. Import & export or Sync calendars.
  3. Export calendar → copy link.
  4. Stay: source Vrbo, room, paste URL, Add feed.

Paste Stay link (Stay → Vrbo)

  1. Same area → Import calendar → paste Stay URL.

Vrbo UI varies by region; search help for “import export calendar” if menus differ.

Channel managers (Cloudbeds, Lodgify, SiteMinder, etc.)

  • Import Stay URL: CM → External calendars / iCal import / blocked dates → paste Stay export URL.
  • Export to Stay: CM → per-room iCal export URL → paste in Stay Add feed (source Other).

Verify sync

  • Stay: Test Feed → “Feed OK” · inbound Last sync · Sync now.
  • Admin → Availability — external blocks shown per room.
  • Website search — OTA-booked dates should not appear as available.

Payments

Settings → Payments configures Stripe and pay-at-property.

  • Stripe — guest pays online; booking confirms via webhook after payment.
  • Pay at property — booking confirms immediately; collect on arrival.
  • Deposits — optional partial charge at booking (configured in tenant settings).

Manage payouts and disputes in your Stripe Dashboard.

Instant check-in & check-out

  • Admin → Instant check-in — scan guest QR or enter check-in code.
  • Each booking gets checkInCode and checkoutCode (also on confirmation).
  • Settings → Check-in — QR templates and checkout automation.
  • Guests use the Check-in tab on their stay portal when enabled.

Troubleshooting

ProblemWhat to check
Unauthorized after sign-in User needs tenant membership; role must be admin/manager/front desk.
OTA still shows available after Stay booking OTA polls slowly (hours). Booking must be CONFIRMED, not PENDING.
Stay shows available after OTA booking Add inbound iCal feed; click Sync now; check lastError on feed.
Double booking Ensure inbound feed mapped to correct room; both directions connected.
iCal feed HTTP error Re-export URL from OTA; URLs expire when regenerated.
Room types wrong on website Edit room name and amenities under Rooms; offers group by type.
Stripe booking missing Payment incomplete — guest must finish Checkout; check Stripe webhook logs.
