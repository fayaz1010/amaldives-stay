# Product Screenshots

These screenshots show the actual Vayves platform UI. They are used in the `/for-guesthouses` landing page.

## Required Screenshots

1. **reservations-calendar.png** - Front desk calendar showing bookings and availability
2. **transport-arrivals.png** - Transport options and arrival scheduling interface
3. **housekeeping-tasks.png** - Housekeeping board with room status and tasks
4. **staff-tasks.png** - Staff management and task assignment view
5. **fnb-minibar.png** - F&B outlets and minibar tracking
6. **logistics-inventory.png** - Inventory management and stock tracking
7. **mira-tax-reports.png** - MIRA tax reporting dashboard
8. **payments-billing.png** - Guest billing and payment interface

## Capture Instructions

To capture these screenshots:
1. Log into https://vayves.com with a demo property account
2. Navigate to each section in the admin panel
3. Take screenshots at 1200x800 or similar desktop resolution
4. Crop and optimize for web (PNG format)
5. Replace placeholder images with actual screenshots
